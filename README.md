# 称完馅再和面（wrap-count）

包包子、饺子、馄饨前先称一称：填面粉、含水率、肉菜调料和每张皮、每个馅多重，算面能出几张皮、馅够包几个、哪样先用完、剩多少，以及补多少面或馅、皮擀多重能刚好一起用完。

- 单页静态应用：`index.html` + `core.js`（计算）+ `ui.js`（界面），不联网、不收集数据，条件只存在本机 localStorage。
- 模型：面团 = 面粉 × (1 + 含水率 + 其他) × (1 − 损耗)；馅 = (肉 + 打水 + 菜 × 挤后剩 + 调料) × (1 − 损耗)；个数往下取整。整数精确计算。
- 测试：`node --test tests/core.test.cjs`；独立 Python 参考实现 `tests/ref.py`（Fraction）生成 `tests/ref.json`（300 组）。
- 默认数字是虚构示例。
